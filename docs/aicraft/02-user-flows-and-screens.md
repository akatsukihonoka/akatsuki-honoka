# 2. ユーザーフローと画面一覧

## 2.1 主要ユーザーフロー

### F1. サインアップ〜初回生成

```mermaid
flowchart TD
  A[LP] --> B[サインアップ: メール/パスワード or マジックリンク]
  B --> C[メール確認]
  C --> D[オンボーディング1: ワークスペース名・業種]
  D --> E[オンボーディング2: ブランド設定<br/>事業概要/ターゲット/トーン/NGワード]
  E --> F[オンボーディング3: 最初のテーマ入力]
  F --> G[AIがコンテンツ案を提案]
  G --> H[案を選択 → 本文生成]
  H --> I[品質検査 自動]
  I --> J[エディタで結果確認]
  J --> K[トライアル開始の案内<br/>Stripe Checkout]
```

### F2. コンテンツ生成〜承認〜公開（中核フロー）

```mermaid
flowchart TD
  A[生成ウィザード: チャネル/目的/テーマ] --> B[案を最大10件提示]
  B --> C[本文生成ジョブ投入]
  C --> D{利用枠・予算OK?}
  D -- No --> D1[生成不可を表示<br/>プラン変更導線]
  D -- Yes --> E[生成]
  E --> F[機械検査]
  F --> G[独立AIレビュー]
  G --> H{合格?}
  H -- No, 試行<3 --> E
  H -- No, 試行=3 --> I[needs_attention<br/>指摘付きで提示]
  H -- Yes --> J[ready_for_review]
  I --> K[エディタで編集]
  J --> K
  K --> L[主張チェックリストを確認]
  L --> M[承認ボタン]
  M --> N[approved]
  N --> O[コピー/エクスポートして顧客が自分で公開]
  O --> P[公開済みマーク・URL記録]
```

### F3. 問い合わせ

```mermaid
flowchart TD
  A[問い合わせフォーム] --> B[顧客対応AIが分類]
  B --> C{カテゴリ}
  C -- 使い方 & FAQ一致度高 --> D[FAQ根拠付き自動回答<br/>解決しない場合は人間へボタン]
  C -- 請求/返金/契約/削除/セキュリティ/苦情/不明 --> E[回答案作成 + エスカレーション]
  C -- 不具合 --> F[再現情報を整理 → 開発タスク起票案]
  E --> G[人間が回答案を確認・修正・送信]
```

### F4. アカウント削除

マイページ → データエクスポート案内 → 削除申請（パスワード再確認）→ 即時ログイン不可・サブスクリプション解約 → 運営者承認 → 完全削除（保持期間は [08](08-security-and-incident-response.md) 参照）→ 完了メール。

### F5. 運営者（人間）の週次フロー

管理コンソール → 承認キュー処理 → 週次レポート確認 → 品質監査サンプル確認 → エスカレーション対応（目標合計 約60分）。

## 2.3 運営者向け管理コンソール（内部）

アクセス条件: `ops_admins` テーブル登録者のみ ＋ MFA必須。顧客データの本文閲覧は「サポート対応で顧客同意あり」の場合のみ、理由入力を必須にして監査ログに記録。

| ID | 画面 | パス（案） | 主要要素 | MVP |
|---|---|---|---|---|
| A-01 | 運営ダッシュボード | `/ops` | 稼働状況、本日のLLMコスト/予算、エラー率、未処理承認数、未対応チケット | M |
| A-02 | 承認キュー | `/ops/approvals` | 申請内容、リスク区分、根拠、差分/プレビュー、承認・却下（理由必須） | M |
| A-03 | チケット | `/ops/tickets` | AI分類、回答案、送信、エスカレーション理由 | M |
| A-04 | エージェント実行ログ | `/ops/agents` | 実行一覧、ツール呼び出し、失敗、停止スイッチ | M |
| A-05 | 品質監査 | `/ops/quality` | 週次サンプル、人間評価入力、AI評価との一致率 | M |
| A-06 | 評価セット結果 | `/ops/evals` | 回帰テスト履歴、閾値比較 | M |
| A-07 | コスト・利用状況 | `/ops/usage` | テナント別消費、異常検知、予算設定 | M |
| A-08 | インシデント | `/ops/incidents` | 起票、重大度、タイムライン、事後レビュー | M |
| A-09 | 機能フラグ / キルスイッチ | `/ops/flags` | AI生成停止、自動回答停止、各エージェント停止 | M |
| A-10 | 営業・マーケ案 | `/ops/marketing` | 市場調査メモ、コンテンツ案、見込み客リスト案、提案文案（送信機能なし） | S |
